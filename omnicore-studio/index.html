OmniCore Studio — Guide

OmniCore Studio runs a large language model directly on your GPU via WebLLM + WebGPU, a sandboxed web preview for HTML/CSS/JS, and a real CPython 3.12 runtime via Pyodide. Nothing you type leaves your device (voice input excepted — it uses your browser's speech service).

Getting started

  1. Pick a model (SmolLM2 1.7B is the fast default; 7–8B models need ~6 GB of GPU memory) and press Load. Weights download once and are cached for offline use.
  2. Ask for code. Every code block in a reply gets Run in Sandbox, Insert, Copy and Download buttons.
  3. Python errors and browser console errors get a Fix with AI button that sends the code and the traceback back to the chat.

Python tips

  • numpy, pandas, matplotlib, scipy, sympy and more load automatically from your imports. plt.show() renders charts in the terminal.
  • Pure-Python packages: %pip install rich in the REPL, or the package button.
  • For input(), open the keyboard panel and type one line per call.
  • The REPL shares variables with the last run of main.py.

Enabling WebGPU

  • Desktop: Chrome / Edge 113+ have it on by default. Firefox 141+ on Windows; Safari 26+ on macOS.
  • Android: Chrome 121+ on most recent devices.
  • iPhone / iPad: Safari on iOS 26+ (or enable WebGPU in Settings › Safari › Advanced › Feature Flags on older versions).
  • No WebGPU? Demo mode keeps the whole workbench usable.

Mobile

Use the bottom tabs or swipe left/right on the panel headers to switch between Chat, Code and Run. While editing on a touch device, a coding key bar appears above the keyboard.
